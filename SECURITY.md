# Security

## Reporting a vulnerability

Email <dan@dbhq.uk> rather than opening a public issue. Include what you found,
how to reproduce it, and what an attacker could do with it. You will get a first
response within 48 hours.

## What this repository does

One skill: deskwork. This repository is currently a scaffold - `skills/deskwork/SKILL.md`
is a stub and the skill is not yet implemented. This section will be filled in
with deskwork's network reach, on-disk behaviour and credential model once the
skill itself lands.

## Third-party code

None. No packages are installed and no dependencies are pulled at runtime.
